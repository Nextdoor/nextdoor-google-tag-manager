# Nextdoor Universal Pixel Community Template

The Nextdoor Universal Pixel community template is a Google Tag Manager [community gallery template repository](https://support.google.com/tagmanager/answer/9454109) that can be used to easily implement Nextdoor Pixel using Google Tag Manager.

[https://github.com/nextdoor/nextdoor-google-tag-manager/issues](https://tagmanager.google.com/gallery/#/owners/Nextdoor/templates/nextdoor-google-tag-manager)

# Publishing an update

The `metadata.yaml` file is used to determine which version of the template to use in the gallery. To publish new versions, add the change number (SHA number) to the versions section of the `metadata.yaml` file. Updates will appear in the gallery typically within 2 to 3 days.

https://developers.google.com/tag-platform/tag-manager/templates/gallery#update_your_template
